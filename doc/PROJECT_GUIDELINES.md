# Build Day The Controlled Build

**Week 1 Project Guide**

Use this guide to build your Week 1 project with AI while keeping control of the scope, the code, and your learning. Your finished project should be a one-page site that you can explain and demonstrate with confidence.

## Learning Objectives

- Build your Week 1 project using AI while staying in control
- Keep a live Prompt Log as evidence of your thinking
- Be able to explain every part of what you built

## Project Requirements

| Category | Requirements |
| --- | --- |
| **Required project files** | `index.html`, `styles.css`, and `main.js` |
| **Required page layout** | A headline, three sections, and one call to action |

## The Four Graded Constraints

1. **Stay in scope** — Three sections, no bonus features.
2. **Explain every part** — You can point at any piece and say what it does, in your words.
3. **Log every prompt** — Log prompts as you go, not after.
4. **Catch one mistake** — Find at least one thing the AI got wrong, fix it, and note it.

## The Build Loop

Do not just paste prompts and accept whatever appears. Run this loop for each piece:

**Prompt → Generate → READ and explain → Verify → Log**

1. **Prompt** — Ask for one section at a time using your Prompt Recipe: Context / Task / Format / Constraints.
2. **Generate** — Let the AI produce it.
3. **Read and explain** — Read what it gave you. Can you say what each part does? If not, ask it to explain until you can. Never paste in code you cannot explain.
4. **Verify** — Does it actually work and match your spec? Try it. Check the edges.
5. **Log** — Drop the prompt, and any fix, into your Prompt Log.

## Control Checklist

- [ ] I'm building only my three sections — no scope creep.
- [ ] I can explain every part I've added so far, in my own words.
- [ ] My Prompt Log is up to date. I logged as I went.
- [ ] I've noted at least one thing the AI got wrong and how I fixed it.
- [ ] I tested it. It actually works, including the obvious edge cases.

## End of Day Self Check

Before you log off, make sure you are demo ready:

- [ ] **A working one-page site** with your headline, three sections, and one call to action.
- [ ] **A Prompt Log** that shows how you built it.
- [ ] **At least one caught mistake** noted, including what it was and how you fixed it.
- [ ] **The ability to explain any part** if asked.
- [ ] **A rough idea of your 2-minute demo** for tomorrow.
